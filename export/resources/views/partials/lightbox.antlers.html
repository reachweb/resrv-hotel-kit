{{# Shared lightbox overlay. Drop it inside an `x-data="lightbox([...])"` root (the component lives in resources/js/site.js); clickable tiles in that root call `open('')`. Browses the image set with the on-screen arrows or the ← / → keys, with an "N / M" counter. Arrows + counter only show when there's more than one image, so it degrades to a plain viewer. A modal dialog while open, like the nav sheet: x-trap moves focus to Close, keeps Tab inside, makes the page behind inert and stops it scrolling. Escape, Close or the backdrop end it, and focus goes back to whatever opened it. #}}
